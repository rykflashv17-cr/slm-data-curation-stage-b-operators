## 已落实的边界

```text
完整源文件列表
  → B01.run_batch：逐条解码一次，统一格式并保存标准数据和完整清单
  → B02.run：仅从标准数据选择统计输入、拟合并输出完整 StatisticsContext
  → B03.run_batch：遍历完整清单，统一判定、报告和可选执行删除
```

B01 不再计算启动排除或 S1 宽限掩码。B02 不再创建适配器或解码 MCAP。CLI 不在算子一、二之间调用 B03，不在 B02 后回跳 B01。启动掩码、缺测判定、S1–S4、报告和删除均在 B03 阶段内。仅保留原来的三个注册 ID。

算子二仍需选择合理的统计输入：输入失败、覆盖不足或非有限数值不得污染统计。该步骤只输出统计纳入 / 排除，不输出质量通过 / 拒绝，也不从批次清单移除文件。B03 消费完整清单并独立执行最终质量规则；相同的测量距离事实由公共纯计算函数提供，该函数不作判定。

保留原采样方式、质量阈值和整条拒绝策略。两个 P0 的修复继续生效：空 / 缺字段 / NaN / Inf 夹爪消息不刷新有效测量时刻；最终质量行时间戳由适配器提供，不按原始消息数量推算。

## 异常路径

| 情况 | B01 | B02 | B03 |
|---|---|---|---|
| 正常与缺测混合 | 全部保存并留在清单 | 正常数据拟合，缺测项记录排除 | 全部输出；缺测明确拒绝 |
| 全部缺测 | 输出标准批次 | 仍执行，返回 `empty` | 执行缺测判断，可在 `run` 中删除明确拒绝项 |
| 全部输入错误 | 每条记录输入错误 | 仍执行，返回 `empty` | 全部报告错误并保留 |
| 关闭覆盖但存在未知数值 | 保留未知事实 | 排除非有限输入 | 数值无法判定，记录错误并保留 |
| B01 中间存储失败 | 阶段失败 | 不启动 | 不启动；源文件保留 |
| 标准文件损坏 / 统计异常 / 引擎返回零统计帧 | 已完成 | 返回 `failed` | 可记录明确的缺测拒绝，其余待数值判断项错误；整批禁止删除 |
| B02 与 B03 覆盖配置不同 | 已完成 | 使用原配置 | 拒绝执行，不默默变更统计人口 |
| API 空批次 | 输出空清单 | 返回 `empty` | 输出零条汇总；CLI 未发现输入时仍提前报错 |

三个阶段之间传递的是完整批次，不会把 `excluded` 直接视为 `rejected`，也不会把 `empty` 视为统计引擎失败。统计失败、逐条错误与删除跳过均需查看汇总，CLI 返回非零执行状态。

本次没有扩展此前按平台场景排除的并发输入变动治理及上游引擎版本缓存失效问题。新增的中间产物指纹仅绑定本次标准数据与配置。
